# Сторонние компоненты

Приложение использует готовые библиотеки и модели. Лицензии собственного
кода и сторонних компонентов — отдельные вопросы; лицензия собственного
кода проекта пока не задана.

| Компонент | Лицензия по метаданным установленного пакета |
| --- | --- |
| PyMuPDF | GNU AGPL 3.0 или коммерческая лицензия Artifex |
| RapidOCR | Apache-2.0 |
| ONNX Runtime | MIT |
| OpenCV Python | Apache 2.0 |
| NumPy | Набор лицензий BSD-3-Clause, 0BSD, MIT, Zlib, CC0-1.0 |
| Pillow | MIT-CMU |
| openpyxl | MIT |
| PyInstaller | GPLv2-or-later со специальным исключением для сборок |

Условия каждого компонента следует смотреть в его поставке. Наличие кода
на GitHub само по себе не предоставляет лицензию на его использование.

Основной OCR — готовая кириллическая модель PP-OCRv5 mobile, загружаемая
RapidOCR. Сведения о дополнительных моделях, обучении и контрольных суммах:
[карточка моделей](src/oge_checker/models/README.md).

Для обучения цифрового классификатора использованы примеры MNIST.
Авторы MNIST: Yann LeCun, Corinna Cortes, Christopher J. C. Burges.
Источник локальной копии: https://github.com/cvdfoundation/mnist.
Исходные учебные примеры и сканы не входят в публичную поставку проекта.
