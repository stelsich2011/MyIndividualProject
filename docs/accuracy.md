# Проверка точности

| Выборка | Результат |
| --- | --- |
| Математические ответы, 20 контрольных страниц | 357/379 — 94,20% |
| Новые сканы, страницы 9–12 | 64/76 — 84,21% |
| Только непустые ответы на страницах 9–12 | 37/48 — 77,08% |

Во втором наборе сравнение выполнялось без учёта регистра; в первом —
по точному совпадению строк. В показатели всех ответов входят пустые поля.
Их нельзя объединять в одну оценку или считать точностью итоговых баллов.
Расшифровка подготовлена с помощью программного ассистента и требует
независимой проверки учителем. Небольшой объём выборки ограничивает выводы.

Программа обрабатывает все 88 страниц первого PDF и 31 страницу второго.
Успешное выделение страницы не означает безошибочное чтение каждого поля.
Сохраняются ошибки распознавания почерка, ФИО, букв и разделителей.

Вкладка «Точность» сравнивает распознавание с отдельной дословной расшифровкой.
Для обучения используются записи со сканов, включая неправильные ответы
учеников; ключи правильных ответов не подменяют эталон OCR.

Перед оценкой новой модели следует заранее отделить контрольные работы,
исключить повторения страниц и по возможности разделить выборки по ученикам.
Рекомендуется отдельно учитывать непустые ответы, ФИО, класс, ошибки
определения пустых полей и правильность выставленных баллов.
