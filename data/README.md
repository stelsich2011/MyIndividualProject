# Локальные датасеты

Исходные данные сохранены на компьютере и исключены из Git.

| Каталог | Содержимое |
| --- | --- |
| `raw/` | Исходные `full_pdf.pdf` и `full_pdf2.pdf` |
| `processed/` | Вырезанные поля, разметка, результаты экспериментов и проекты |
| `external/mnist/` | Исходные изображения и метки цифр MNIST |

Данные нужны для обучения и дополнительных интеграционных проверок.
Для обычного запуска приложения достаточно готовых моделей из
`src/oge_checker/models`. Веса моделей и содержимое датасетов при
реорганизации не изменялись.

Некоторые старые JSON содержат абсолютные пути исходного расположения как
метаданные предыдущих прогонов. Относительные пути внутри перенесённых наборов
сохранены. Новые прогоны записывают актуальные пути.

Не размещайте реальные сканы и расшифровки с персональными данными в публичном
репозитории. Для примеров используйте синтетические или обезличенные материалы.
